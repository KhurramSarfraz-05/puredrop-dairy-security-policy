# PureDrop Dairy Security Policy Pack

## Project overview
This repository contains a simple, practical security policy pack prepared for **PureDrop Dairy**. The policies are intended to help staff protect company accounts, employee information, delivery information, and the devices used for daily operations.

## Client
- **Client:** PureDrop Dairy
- **Prepared by:** Khurram Sarfraz
- **Technology area:** Cyber Security

## Project contents
- `password_policy.md` — rules for creating, using, and protecting passwords.

Additional documents planned for later tasks:
- Device Policy
- Access Policy
- Staff Security Checklist
- Compiled Policy PDF
- Static policy website
- Handover and maintenance notes

## Current status
**Task 1:** Repository setup and Password Policy draft.

## How to use
Open `password_policy.md` to review the password rules. Staff should follow the policy whenever they create or use an account for PureDrop Dairy work.

## Review and maintenance
The policy should be reviewed periodically and whenever the organisation changes the systems or services used to handle its information. The business owner or an assigned manager should approve policy changes before they are treated as official.
